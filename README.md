## 🔨 Systems Engineering

One of my recent projects is **FlashKV**, a Redis-compatible in-memory database written from scratch in C++17.

**[Explore FlashKV →](https://github.com/Chandi977/FlashKv)**

```text
TCP Server
   ↓
RESP Protocol Parser
   ↓
Command Processor
   ↓
Thread-Safe In-Memory Store
   ↓
TTL + Persistence + Async Logging
```

Features include:

- Redis-compatible RESP protocol
- Concurrent client handling
- Key expiration / TTL
- RDB-style persistence
- String, List and Hash operations
- Pipelining support
- Docker deployment
- Async logging
